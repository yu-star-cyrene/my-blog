Linux 命令通常有两种输出：

| 编号 | 名称              | 含义     |
| ---- | ----------------- | -------- |
| `1`  | 标准输出 `stdout` | 正常结果 |
| `2`  | 标准错误 `stderr` | 错误提示 |

例如：

```bash
ls /etc
```

正常列出文件，这是标准输出 `1`。

```bash
ls /不存在
```

出现：

```text
ls: cannot access '/不存在': No such file or directory
```

这是标准错误 `2`。



```bash
ls /不存在 2> error.txt
```

终端不会显示错误，而是把错误保存到：

```text
error.txt
```

```bash
ls /不存在 2>> error.txt
```



```bash
2>&1
```

拆开理解：

- `2`：标准错误
- `>`：重定向
- `&1`：重定向到文件描述符 `1`

也就是：

> 把标准错误 `2` 重定向到标准输出 `1` 当前指向的位置。

例如：

```bash
ls /etc /不存在 > result.txt 2>&1
```

这里执行顺序是：

1. `> result.txt`：正常输出写入 `result.txt`
2. `2>&1`：错误输出也写到标准输出所在的位置
3. 所以正常信息和错误信息全部进入 `result.txt`
