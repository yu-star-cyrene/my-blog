什么是进程？

可以这样理解：

- **程序**：硬盘上的代码文件
- **进程**：程序运行起来后的实例

例如：

```
/bin/bash
```

是一个程序文件。

当打开终端运行它时，系统会创建一个 Bash 进程。

同一个程序可以同时产生多个进程。例如同时打开四个终端，就可能有四个 Bash 进程，每个进程都有不同的 PID。



PID 是 Process ID，也就是进程编号。

例如：

```
PID 69
```

表示这个进程的编号是 69。系统通过 PID 区分和管理进程。

查看指定 PID：

```
ps -p 69
```

查看更详细的信息：

```
ps -fp 69
```



结束指定进程：

```
kill 69
```

强制结束：

```
kill -9 69
```





一个进程可以创建另一个进程。

例如你在 Bash 中执行：

```
ps
```

关系大致为：

```
bash
└── ps
```

此时：

- `bash` 是父进程
- `ps` 是子进程

查看父进程 PID：

```
ps -o pid,ppid,cmd
```

其中：

- `PID`：自己的进程号
- `PPID`：父进程的进程号

查看树状关系：

```
ps -ef --forest
```

或者：

```
pstree -p
```





`STAT` 一列中常见字母：

| 状态 | 含义                         |
| ---- | ---------------------------- |
| `R`  | 正在运行或等待 CPU           |
| `S`  | 正在休眠，等待某个事件       |
| `D`  | 不可中断休眠，常见于磁盘 I/O |
| `T`  | 已暂停                       |
| `Z`  | 僵尸进程                     |
| `s`  | 会话首进程                   |
| `+`  | 当前终端的前台进程组         |

```
Ss+
```

可以理解为：

- `S`：当前在等待输入
- `s`：它是会话首进程
- `+`：属于当前终端的前台进程组

```
R+
```

表示该进程正在运行，并且位于终端前台。
